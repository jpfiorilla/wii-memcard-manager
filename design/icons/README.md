# App icon concepts

- `memcard-grid.svg`: **in use** (copied to `public/app-icon.svg`; `build/icon.*` rendered from it). 5x5 dots = the 25-recording card.
- `memcard-wifi.svg`, `memcard-sync.svg`: alternates, same style, kept for later use.

All are 1024x1024 macOS-style squircles in the app palette (#0d0221 / #ff1493 / #7ee8ff).
